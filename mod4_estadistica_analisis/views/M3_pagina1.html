Recopilar Datos

Reúne datos de falla para el activo que estás analizando. Necesitarás los tiempos exactos de falla para cada equipo o activo.

Importante: Los datos deben representar tiempos hasta la falla de equipos similares operando bajo condiciones similares.

Simulador de Datos de Falla

2

Ordenar los Datos

Ordena los tiempos de falla de menor a mayor y asigna un rango (del 1 al n) para cada tiempo de falla.

Este ordenamiento es fundamental para los cálculos posteriores de probabilidad.

Datos Ordenados

Orden (i) Tiempo entre fallas (t)
3

Calcular Probabilidades de Falla

Utiliza el método de Rangos Medianos u otros métodos para calcular las probabilidades de falla. Una fórmula común para esto es:

Fórmula de Probabilidad:
Fi = i / (n + 1)

Donde:

  • Fi = Probabilidad de falla
  • i = rango
  • n = número total de fallas

Cálculo de Probabilidades

Orden (i) Tiempo entre fallas (t) RM [F(t)]
4

Transformar los Datos

Calcula el logaritmo natural tanto de los tiempos de falla como del logaritmo natural del logaritmo natural negativo de las probabilidades de falla.

Eje X:
x = ln(tiempos de falla)
→
Eje Y:
y = ln(−ln(1 − Fi))

Datos Transformados

Orden (i) Tiempo entre fallas (t) RM [F(t)] X [ln(t-θ)]
5

Graficar los Datos

Grafica los datos transformados (x, y) en papel gráfico regular o utiliza software estadístico. Calcular Probabilidades.

Los puntos deben formar aproximadamente una línea recta si los datos siguen una distribución Weibull.

Interpretar los Parámetros

Utiliza los β y η estimados para comprender el comportamiento de falla de tu sistema y planificar estrategias de mantenimiento en consecuencia.

  • β (pendiente): Factor de forma que indica el tipo de falla
  • η (intercepto): Vida característica del componente
