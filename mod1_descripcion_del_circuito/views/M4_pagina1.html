Sistema de Embolsado

Objetivo del Sistema

Llenar, pesar y empacar maxi sacos de un peso predeterminado, entre 1 a 2 toneladas, de concentrado de molibdeno seco y enfriado.

El sistema de ensacado consiste en una tolva de almacenamiento con fondo vibratorio y tornillo alimentador más un sistema de sujeción de sacos, balanza, mesa de polines y red de aire para operar válvulas y actuadores para la operación del sistema de ensacado.

Flujo del Concentrado en el Sistema de Embolsado

El concentrado cae por gravedad y vibración desde la tolva almacenamiento concentrado molibdeno (3410-BN-001) hacia el alimentador tornillo descarga tolva concentrado de molibdeno (3410-CS-005) el cual dirige el concentrado a los maxi sacos que se cargan en una balanza (3410-SC-001), para determinar la tara (carga) y el peso cargado en cada saco. El sistema de llenado de sacos registra los pesos e imprime en los sacos.

📥 Entrada del Concentrado

Tolva almacenamiento (3410-BN-001) con fondo vibratorio.

🔄 Alimentador Tornillo

Alimentador tornillo descarga (3410-CS-005) dirige el concentrado.

⚖️ Pesaje y Registro

Balanza (3410-SC-001) determina tara y peso cargado.

Componentes Clave del Sistema de Embolsado

🎯

Sistema de Sujeción de Sacos

Mantiene los maxi sacos en posición durante el llenado. Permite el inflado con aire comprimido.

⚖️

Balanza (3410-SC-001)

Determina tara y peso cargado. Registra datos para impresión automática.

💨

Red de Aire Comprimido

Proporciona aire para inflar sacos y operar válvulas y actuadores del sistema.

🛞

Mesa de Polines

Facilita el movimiento de sacos llenos hacia las siguientes etapas del proceso.

🚚

Transportadores Motorizados

Trasladan sacos llenos hacia estación de etiquetado de forma controlada.

🏷️

Impresora Térmica (3410-XM-002-IL1)

Rotula automáticamente el peso registrado en cada saco para trazabilidad.

Parámetros de Operación del Sistema

📊 Rango de Peso

Maxi sacos: 1 a 2 toneladas predeterminadas.

⚙️ Control de Velocidad

Alimentador reduce velocidad al alcanzar ~80% del peso para precisión.

💾 Registro de Datos

Balanza (3410-WIC855) registra tara y peso de cada saco.

🔄 Ciclo Continuo

Sistema permite operación continua durante toda la jornada laboral.

🎯 Precisión de Pesaje

Sistema garantiza consistencia en el peso de cada maxi saco.

📍 Trazabilidad Completa

Etiquetado automático permite identificar peso y lote de cada saco.
